Create a premium, highly animated Indian wedding invitation website for:

BHUNESH & SONALI

The website should feel like a luxury digital wedding invitation / cinematic wedding story.

IMPORTANT:

I will provide multiple wedding videos named in sequence:

video-1.mp4

video-2.mp4

video-4.mp4

VIDEO EXPERIENCE

Use them in exact sequence:

video-1.mp4

video-2.mp4

video-3.mp4

video-4.mp4

video-5.mp4

video-6.mp4

Requirements:

- Lazy-load videos where appropriate.

- Do not load all videos at maximum quality simultaneously.

- Use poster images where possible.

- Use playsinline.

- autoplay muted where browser policies require it.

- Provide graceful fallback if a video cannot load.

- Never stretch videos.

- Maintain correct aspect ratio.

- Use object-fit: cover for cinematic sections.

- On mobile, make sure the important content remains visible.

Each video section should transition using:

- crossfade

- scale

- blur-to-sharp

- opacity

- subtle parallax

Do NOT use excessive transitions.

==================================================

SCROLL ANIMATIONS

==================================================

Use IntersectionObserver for scroll-triggered animations.

Animations should include:

1. Text fade-up

2. Image/video scale-in

3. Gold line drawing

4. Floral elements floating

5. Petals falling

6. Section reveal

7. Soft blur → sharp

8. Slow parallax

9. Number animations

10. Timeline cards sliding in

Use CSS transforms and opacity for performance.

Respect:

prefers-reduced-motion

When reduced motion is enabled:

- remove large movement

- disable continuous particles

- keep simple fades
